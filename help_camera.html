Camera Setup & High-FPS Streaming Tutorial

Optimizing Cameras, RTSP Streams, Resolution Presets, and Multi-Threaded Inference

1. Supported Video Sources

USB & Built-in Webcams

Supports indices 0, 1, 2, etc. Click the Scan button in the Camera Dock to auto-discover all connected cameras.

RTSP / IP Security Cameras

Enter any RTSP stream in the Stream URL field, e.g. rtsp://admin:password@192.168.1.100:554/stream1.

HTTP / MJPEG & Video Files

Supports live HTTP streams, screen virtual cameras (OBS Virtual Camera), or path to local .mp4 video files.

3. High-FPS Architecture: How Decoupled Threads Work

Unlike standard detection apps that stutter when running heavy AI models, this suite uses a decoupled multi-threaded pipeline:

  • Capture Thread: Pulls raw frames from hardware at the camera's full native refresh rate (30 to 60+ FPS) without dropping frames.
  • Inference Thread: Processes incoming frames with the active neural network asynchronously.
  • UI Thread: Renders smoothly in Qt, so zooming, panning, and interacting with controls never stutters.

4. Automated Interval Auto-Saving

In the Camera Control Dock, enable Auto-Save Every: and set an interval (e.g. 2.0 s):

  • The system automatically writes the frame to disk alongside a corresponding JSON annotation file with detected boxes and labels.
  • Ideal for unattended dataset collection (e.g. collecting training data of parts on a conveyor, cars passing, or gestures).
